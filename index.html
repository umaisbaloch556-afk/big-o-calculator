Comprehensive Guide to Big-O Notation

Big-O notation is a mathematical classification used in computer science to describe the upper bound of an algorithm's execution time or memory space usage relative to the input size (N). It measures asymptotic efficiency rather than exact wall-clock time.

Common Time Complexity Classes Explained

  • O(1) - Constant Time: Execution time remains fixed regardless of input size. Example: Accessing an array element by index or retrieving a key from a hash map.
  • O(log N) - Logarithmic Time: The operational step count scales logarithmically. Halving problem sets each step makes this extremely efficient. Example: Binary Search.
  • O(N) - Linear Time: Execution time scales linearly in direct proportion to input size N. Example: Iterating through an unsorted array via a single loop.
  • O(N log N) - Linearithmic Time: Common in optimized comparison-based sorting algorithms like Merge Sort, Quick Sort, and Heap Sort.
  • O(N²) - Quadratic Time: Performance degrades rapidly as N grows due to nested iteration over the dataset. Example: Bubble Sort, Insertion Sort, or Selection Sort.
  • O(2ⁿ) - Exponential Time: Operations double with every increment in input size N. Frequently seen in brute-force recursive solutions like recursive Fibonacci calculations.
